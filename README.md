## 한눈에 보기 (비전공자용)

반도체 공장에서는 아주 작은 불량도 제품 전체를 망가뜨릴 수 있습니다.  
이 프로젝트는 **전자현미경으로 찍은 반도체 사진을 AI가 보고, 어떤 종류의 불량인지 자동으로 맞춰 보게** 만드는 것이 목표입니다.  
나중에 그 AI를 **FPGA**라는 전용 칩에 올려서, 현장에서 더 빠르고 효율적으로 검사하는 것까지 계획하고 있습니다.

---

### 1) 데이터는 뭘 썼나?

공개 데이터셋 **Carinthia-S**를 사용했습니다.  
([Zenodo 공개본](https://zenodo.org/records/16895427))

| 쉽게 말하면 | 내용 |
| --- | --- |
| 이게 뭐야? | 실제 반도체 웨이퍼를 **SEM(전자현미경)** 으로 찍은 불량 사진 |
| 몇 장? | **4,591장** |
| 무엇을 맞추나? | 불량 종류 **6가지** 중 무엇인지 분류 |
| 추가로 있는 것 | 불량 위치를 표시한 **마스크 이미지**도 함께 있음 |
| 특징 | 종류별 사진 수가 매우 다름 (어떤 종류는 수천 장, 어떤 종류는 몇 장) |

학습할 때 사진을 나눠 썼습니다.

- 학습용(공부): 약 70%
- 검증용(중간 확인): 약 15%
- 시험용(최종 채점): 약 15%

> 왜 이 데이터?  
> 웨이퍼맵(숫자 격자)이 아니라 **실제 반도체 SEM 사진**이라, “불량 이미지를 AI로 본다”는 우리 주제와 가장 잘 맞아서입니다.

---

### 2) 모델은 어떻게 돌렸나?

쉽게 비유하면, AI에게 **불량 사진 문제집**을 여러 번 풀게 한 뒤 시험을 본 것입니다.

| 단계 | 한 일 |
| --- | --- |
| 준비 | 사진 크기를 224×224로 맞추고, 밝기·방향 등을 조금씩 바꿔서 더 잘 배우하게 함 |
| 모델 | **ResNet18** (이미지를 보고 종류를 고르는 표준 AI 모델) |
| 시작점 | 미리 학습된 눈(ImageNet 사전학습)을 가져온 뒤, 우리 불량 사진에 맞게 다시 학습 |
| 불균형 대응 | 사진이 적은 종류도 골고루 보게 **가중 샘플링** 사용 |
| 학습 횟수 | **5번(epoch)** 전체 훑기 (빠른 첫 실험) |
| 실행 환경 | Mac (Apple GPU, MPS) |
| 저장 | 가장 잘 나온 모델을 `results/checkpoints/best.pt`에 저장 |

명령어로 보면 이 흐름입니다.

```bash
python scripts/preprocess.py   # 사진 목록을 학습/검증/시험으로 나누기
python scripts/train.py --epochs 5
python scripts/evaluate.py     # 시험 점수로 채점
```

---

### 3) 성능은 어떤가? (첫 베이스라인)

시험용 사진으로 채점한 결과입니다.

| 지표 | 점수 | 쉽게 말하면 |
| --- | --- | --- |
| Accuracy (정확도) | **97.97%** | 전체 문제 중 맞힌 비율 |
| F1-score (macro) | **0.756** | 종류별로 얼마나 고르게 잘했는지 |
| Precision (macro) | **0.729** | “이 종류다”라고 했을 때 진짜인 비율 |
| Recall (macro) | **0.826** | 실제 그 종류를 놓치지 않고 찾아낸 비율 |
| 검증 최고 정확도 | **99.27%** | 학습 중 중간 확인에서 가장 좋았던 점수 |

**해석**

- 전체 정답률은 매우 높습니다.
- 다만 사진이 많은 종류에 점수가 쏠릴 수 있어서, **종류별 균형 점수(F1)** 는 정확도보다 낮게 나왔습니다.
- 즉 “대체로 잘 맞히지만, 희귀한 불량까지 똑같이 잘하진 못한다”는 뜻입니다.  
  다음 단계에서는 희귀 클래스 보강·더 긴 학습·다른 모델 비교를 할 예정입니다.

결과 파일

- 점수: [`results/metrics/test_metrics.json`](results/metrics/test_metrics.json)
- 혼동 행렬(어디에 헷갈렸는지): [`results/figures/confusion_matrix.png`](results/figures/confusion_matrix.png)

## 목표

반도체 공정 이미지를 AI로 분석해 불량 여부와 유형을 자동 판별하고, FPGA 가속을 통해 현장에서 즉시 활용할 수 있는 고속 추론 시스템을 구축한다.

## 파이프라인

```
반도체 이미지 입력
        ↓
이미지 전처리
        ↓
관심 영역 검출
        ↓
AI 모델 추론
        ↓
정상·불량 판별
        ↓
불량 유형 분류 및 위치 표시
        ↓
결과 시각화·저장
```

## 진행 Phase

1. **이미지 데이터 확보** — 공개 데이터셋 조사·선정 ✅
2. **판독 기준 및 파이프라인 설계** — 전처리·판정 규칙 ✅ (초기)
3. **모델 학습 및 성능 평가** — 베이스라인 완료 ✅ (ResNet18, 5 epoch)
4. **FPGA 기반 추론 가속** — 경량화·양자화·배포
5. **실시간 카메라 연동** (여유 시)
