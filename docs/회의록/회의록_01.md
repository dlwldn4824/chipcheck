# 프로젝트 회의록 #1

## 프로젝트 주제

### AI 기반 반도체 불량 이미지 분석 SW

- 반도체 공정 이미지를 분석해 불량 여부 및 불량 유형을 판별하는 AI 소프트웨어 개발
- 학습된 모델을 **FPGA 기반 추론 가속기**에 적용해 실시간 처리 성능 향상

---

## 프로젝트 목표

> 반도체 이미지를 AI로 분석해 불량을 자동 판별하고, FPGA 가속을 통해 현장에서 즉시 활용할 수 있는 고속 추론 시스템을 구축한다.

## 첫 회의 핵심 논의사항

### 1. 학습 데이터 찾기

- 공개 데이터셋 조사
- 이미지 수·불량 유형·품질·라벨 신뢰도·사용 가능 여부 확인

### 2. 판독 파이프라인 구축

- 전처리 방식 결정
- 분류 vs 객체 탐지 우선순위
- 모델 후보·판정 임계값·시각화 방식

### 3. 초기 학습 진행

두 번째 회의 전까지 기본 파이프라인 구축 및 초기 학습 결과 확인
