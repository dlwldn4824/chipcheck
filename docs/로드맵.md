# 프로젝트 로드맵

연구 기간: **2026.07.01 ~ 2026.11.30**

## Phase 1. 이미지 데이터 확보

**목표:** 학습용 반도체 불량 이미지 데이터를 확보하고 품질을 검토한다.

- 공개 반도체 불량 이미지 데이터셋 조사
- 정상·불량 이미지 수 / 불량 유형·클래스 구성 확인
- 해상도·촬영 환경·라벨 정확도·클래스 불균형 검토
- 사용 가능 데이터셋 최종 선정

**확인 기준:** 전체 이미지 수, 정상/불량 비율, 불량 유형 수, 해상도, 촬영 조건, 라벨 형식, 상업·연구 사용 가능 여부

## Phase 2. 판독 기준 및 파이프라인 설계

**목표:** 입력 → 판정 결과까지의 분석 구조를 설계한다.

전처리 후보: 크기 통일, 밝기·대비 보정, 노이즈 제거, 정규화, 회전·위치 보정, 데이터 증강

판독 규칙: 이진 분류 / 다중 분류 / 영역 검출 / 신뢰도 임계값 / 낮은 신뢰도 재검토 / 반복 판정 기준

## Phase 3. 모델 학습 및 성능 평가

모델 후보: CNN, ResNet, EfficientNet, MobileNet, YOLO, FPGA용 경량 모델

평가 지표: Accuracy, Precision, Recall, F1, Confusion Matrix, 클래스별 성능, 장당 추론 시간

## Phase 4. FPGA 기반 추론 가속

- 모델 경량화, 연산 제거, 양자화, 배포 형식 변환
- FPGA 추론 파이프라인 구축
- CPU·GPU·FPGA 비교 (속도 / 지연 / 전력 / 정확도 / 비용)

## Phase 5. 실시간 카메라 연동 (조건부)

초기 학습·FPGA 적용이 빠르게 끝나면 카메라 입력을 연동한다.

```
카메라 → 실시간 전처리 → FPGA 추론 → 불량 판정 → 위치 표시 → 화면·로그 저장
```

## 최종 산출물

**기술:** 분석 모델, 판별 SW, FPGA 가속기, 카메라 연동, 시각화 대시보드  
**발표·연구:** 포스터, PPT, 기술 보고서, 논문 초안, 성능·FPGA 비교표
